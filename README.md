# LeetCode Solutions

Персональная база решений алгоритмических задач с платформы LeetCode.
Использую данный репозиторий для прокачки навыков проектирования и оптимизации алгоритмов, а также подготовки к техническим интервью.

## Технологический стек и специализация
* **Системное программирование & Сложные алгоритмы (Core)**: **C++** — разработка высокопроизводительных систем, низкоуровневых компонентов и закрытых наукоемких алгоритмов. Экспертиза в сжатии данных и помехоустойчивом кодировании: реализация декодеров LDPC, кодеков стандарта V.44 (LZJH) и алгоритмов Inflate.
* **Коммерческая Backend-разработка (Python)**: **более 5 лет (Middle+)** промышленного опыта проектирования высоконагруженных REST API систем и микросервисов (**FastAPI, PostgreSQL, Redis, Docker**). 
  * *Архитектура и БД*: Перевод систем на асинхронный стек (async SQLAlchemy), оптимизация горячих путей через прогрев Redis-Set'ов, управление миграциями (Alembic) и сложной бизнес-логикой.
  * *Инфраструктура*: Настройка систем мониторинга, алертинга и сбора кастомных бизнес-метрик (**Prometheus, Grafana**).
* **Продуктовая разработка & AI (Go)**: **Go (Golang / Fiber v3)** — промышленный опыт интеграции LLM-провайдеров (**YandexGPT gRPC SDK**, валидация/модерация контента), разработка высокопроизводительных микросервисов, легковесных фасадов, утилит с низким latency и многопоточных решений.

## Структура репозитория
Все решения автоматически распределяются расширением по уровням сложности и содержат код программы вместе с условием задачи:
`[Сложность]/[Номер_Название_Задачи]/`
